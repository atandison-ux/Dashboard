# 🎮 Xbox Game Pass Subscriptions Sales Dashboard

Este projeto foi desenvolvido como parte de um desafio de análise de dados e criação de dashboard no **Microsoft Excel**, utilizando informações fictícias de assinaturas do **Xbox Game Pass**.

---

## 📊 Dados Utilizados

O arquivo `dashboard-xbox.xlsx` contém:

- **Bases de Assinantes**: ID, Nome, Plano, Data de Início, Auto Renovação, Preço da Assinatura, Tipo de Assinatura.  
- **Passes Adicionais**: EA Play Season Pass e Minecraft Season Pass.  
- **Cálculos de Negócio**:
  1. Faturamento total de vendas de planos anuais.
  2. Faturamento total de vendas de planos anuais, separado por auto-renovação e não auto-renovação.
  3. Total de vendas de assinaturas do EA Play.
  4. Total de vendas de assinaturas do Minecraft Season Pass.  

---

## 🚀 Objetivo

O objetivo principal é **responder perguntas de negócio** através de análises de dados e consolidar os resultados em um **dashboard visual**.

---

## 🛠️ Ferramentas

- **Microsoft Excel** → para cálculos, tabelas dinâmicas e criação do dashboard.  
- **GitHub** → para versionamento e entrega do projeto.
